# **App Name**: BracU Grad Portfolio

## Core Features:

- Resume Showcase: Display your resume with education, skills (python, DL, networking), and experience.
- Project Portfolio: Showcase your projects (hospital management website, donation management webapp, car company website) with descriptions and links.
- Contact and Social Links: Include a contact form and links to your LinkedIn and GitHub profiles.

## Style Guidelines:

- Primary color: Dark blue (#003049) to convey professionalism.
- Secondary color: Light gray (#D6D6D6) for backgrounds and subtle contrasts.
- Accent: Teal (#40E0D0) for interactive elements and highlights.
- Clean and readable sans-serif fonts for headings and body text.
- Use a single-page layout with smooth scrolling for easy navigation.
- Use simple, professional icons for skills and contact information.
